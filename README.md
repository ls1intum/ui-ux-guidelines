# UI-UX Guidelines @ AET
UI-UX guidelines for applications developed at AET https://github.com/ls1intum

The guidelines are published at https://ls1intum.github.io/ui-ux-guidelines/.

## Contribute

We are using [Docusaurus](https://docusaurus.io/) to provide the guidelines. The site lives in the [guidelines](guidelines) folder.

Quick start (requires the Node.js version in [.nvmrc](.nvmrc)):

```bash
cd guidelines
npm ci
npm start
```

You can find further contributing info, including how to add a new page, in the [guidelines/README.md](guidelines/README.md) file.
